# Ночной Курьер / Night Courier

Вертикальная 3D-аркада на **Godot 4.3**, Android-first MVP. Один ночной район, короткие доставки, риск и постоянный прогресс. Без сторонних ассетов и платных зависимостей.

[![Build](https://github.com/din820553-debug/Game/actions/workflows/android.yml/badge.svg)](https://github.com/din820553-debug/Game/actions/workflows/android.yml)

## Скачать Android APK

1. Откройте [Actions → Godot checks and Android APK](https://github.com/din820553-debug/Game/actions/workflows/android.yml).
2. Выберите последний **успешный** запуск.
3. В разделе **Artifacts** скачайте **night-courier-android-debug** (нужен вход в GitHub).
4. Распакуйте ZIP и установите `night-courier-debug.apk` на Android, разрешив установку из этого источника.

Это тестовый APK для ARMv7/ARM64, не публикация в Google Play.
CI создаёт временный debug-ключ: при переходе между сборками может потребоваться удалить старую версию, что удаляет локальный прогресс. Для постоянных обновлений нужен стабильный ключ подписи в GitHub Secrets.

В артефакте **night-courier-checks** находятся логи и пять автоматически отрисованных экранов.

## Запуск на компьютере

Скачайте репозиторий через **Code → Download ZIP** или клонируйте его. Импортируйте `project.godot` в Godot **4.3 stable**, нажмите **F6/F5**. Нужна стандартная версия, .NET не требуется.

- Телефон: свайп по нижней панели — сменить полосу; удержание — ускориться; кнопка «Нитро» — рывок.
- Компьютер: A/D или ←/→; удерживать ↑ для ускорения; пробел — нитро; Esc — пауза.
- Фоновый режим автоматически включает паузу. При принудительном закрытии посреди доставки заработок текущей смены теряется.

## Что входит в MVP

- Процедурный 3D-город: дождь, неон, фонари, трафик и стилизованные отражения.
- Один район; велосипед и покупаемый скутер с разными характеристиками.
- 20 типов грузов; три разных предложения: спокойное, среднее и рискованное.
- Расстояние, оплата, риск, срок и район в каждом предложении.
- Поездки обычно 1–3 минуты на стартовом транспорте; прокачка сокращает время.
- 12 событий с решениями: полиция, погоня, авария, перекрытие, кража, новый адрес, покупатель, организация, поломка, короткий путь, ловушка, находка.
- Риск показывает вероятность событий на контрольных точках, а не вероятность провала; столкновения возможны при любом риске.
- Деньги в банке защищены. Доход смены можно потерять в следующей поездке или забрать в гараже.
- Серия доставок: до +120% оплаты и +20% скорости. Гараж сбрасывает серию.
- Четыре улучшения Lv.1–10, отдельно для каждого транспорта.
- Пять репутаций с игровыми эффектами.
- 7 видов находок × 5 редкостей, экран коллекции.
- Локальное сохранение с проверкой схемы, временным файлом и резервной копией.
- Простое синтезированное аудио транспорта, выключаемое в гараже.

Новые районы, бизнес, наём курьеров и полноценный парк из шести машин **не входят** в этот этап. Визуал процедурный, модели упрощённые; экономика и сложность требуют тестирования на игроках.

## Архитектура

| Файл | Назначение |
|---|---|
| `data/catalog.gd` | Заказы, районы, транспорт, события, редкости |
| `scripts/game_state.gd` | Экономика, поездка, RNG, последствия, награды |
| `scripts/save_store.gd` | Версионированные сохранения и восстановление |
| `scripts/city.gd` | 3D-визуализация, движение, трафик |
| `scripts/main.gd` | Экраны, touch/keyboard, пауза |
| `tests/test_game.gd` | Детерминированные проверки логики и UI |
| `tests/capture.gd` | Снимки настоящей 3D-сцены и интерфейса |
| `ci/` | Проверка ошибок Godot и настройка Android |

Подробности расширения: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Проверки

```sh
godot --headless --editor --path . --import
godot --headless --path . --script res://tests/test_game.gd
```

CI дополнительно проверяет ошибки в логах, рисует экраны через Mesa/Xvfb, экспортирует APK и проверяет подпись. Автотесты не заменяют проверку касаний, производительности и установки на физических устройствах.

## Android и iOS

**Android:** готов preset `Android`. Для локального экспорта установите шаблоны Godot 4.3, JDK 17, Android SDK platform 34 / build-tools 34.0.0 и укажите SDK/JDK в настройках редактора.

**iOS:** исходники Godot совместимы с экспортом на iOS, но подписанная iOS-сборка в этом MVP не настроена и не проверена. Нужны macOS, Xcode, iOS export templates, Apple Developer Team и профиль подписи. Создайте iOS preset в Godot, задайте Bundle ID и Team ID, экспортируйте Xcode-проект и подпишите его. Секреты и сертификаты в репозиторий не добавляйте.

Сохранение находится в `user://night_courier_v1.json`; на ПК путь доступен через **Project → Open User Data Folder**.
